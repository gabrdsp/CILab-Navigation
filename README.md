# 🌐 Computational Intelligence Laboratory — Navigation

This project is a **single-page web application** that serves as a central hub for the **Computational Intelligence Laboratory (CILab)**.
It allows CILab to share multiple social and professional links from a single, visually appealing and accessible page — ideal for sharing on social media profiles or research project pages.

---

## 🚀 Overview

The application replicates a “Linktree”-style layout, designed specifically for the **CILab** identity.
It displays a responsive, gradient background, a central card with the lab’s logo, and clear action buttons that redirect users to different official channels.

Each link opens in a new browser tab for convenience and accessibility.

---

## 🧩 Features

* ✅ **Single-page design** — minimal, elegant, and easy to navigate
* 🎨 **Gradient background** — using CILab’s color palette ( #FFB063, #28C1E0, #FF6853)
* 📱 **Responsive layout** — optimized for mobile, tablet, and desktop
* ♿ **Accessible** — keyboard navigation, ARIA labels, and proper color contrast
* 🔗 **External links** — open securely with `rel="noopener noreferrer"`
* 🧪 **Unit-tested components** — verified using Jest and React Testing Library

---

## 🧰 Technologies Used

### 🖥️ Frontend

* **React (Vite)** — for fast, modern component-based UI development
* **Tailwind CSS** — for utility-first responsive styling and custom theme colors

### 🧪 Testing

* **Jest + React Testing Library** — to ensure components render and behave correctly

### ⚙️ Build System

* **Vite** — provides ultra-fast hot module reloading and optimized builds
* **PostCSS + Autoprefixer** — ensures cross-browser compatible CSS
